Kichray WeaponLab 0.2.0 — результаты проверки

8/8 переносимых наборов тестов: прошли.
8/8 наборов ASan/UBSan: прошли, LeakSanitizer отключён.
Компилятор: GCC 13.3.0, C++17.

Проверены: LTX/XML, кодировки, наследование, секции патронов и резервные копии;
DDS/OGF/OMF; ввод камеры и шесть направлений; лабораторные формулы стрельбы;
прозрачные иконки, крупные/неквадратные атласы и клеточная запись;
ImGui, ступени колёсика, перенос описания и элементы симуляции/сцены.

Renderer.cpp/Renderer.h, FlightInput.h, Preview.hlsl, значок и заставка
побайтово совпадают с базой Material Lab 0.13.0. В общем DDS-загрузчике
изменён только предел стороны: 8192 -> 16384, при прежнем лимите 16 Мп.

Сборка и запуск Windows здесь НЕ выполнены: компилятор и Windows SDK отсутствуют.
Включены проект MSVC2022, CMake и нативная проверка --smoke-test:
D3D11/WARP, шесть осей, исключение скрытого меша, прозрачный PNG через WIC.
GitHub Actions настроен для Windows и Linux; успешный запуск CI не заявляется.
Реальная gamedata пользователя и запуск в игре не проверены.

Полные команды и результаты — portable-tests.txt и asan-ubsan-tests.txt.
Хеши проверенных исходников — build-validation.json.
